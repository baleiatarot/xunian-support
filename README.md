# 續念｜使用支援

《續念》的公開簡介、使用支援及隱私政策網站。

## 啟用 GitHub Pages

Settings → Pages → Build and deployment：

- Source：Deploy from a branch
- Branch：main
- Folder：/(root)
- Save

發布完成後：

- 首頁：https://baleiatarot.github.io/xunian-support/
- 支援：https://baleiatarot.github.io/xunian-support/support.html
- 隱私政策：https://baleiatarot.github.io/xunian-support/privacy.html

以上網址需啟用 Pages 並部署成功才可使用。

## 更新

直接編輯對應 HTML，保留共用導覽和相對路徑。資料處理方式改變時，同時更新 privacy.html 與日期。本站不含分析工具、廣告、表單或外部字型；GitHub 主機的安全連線紀錄已在政策中說明。

## 檔案

- index.html：簡介
- support.html：使用支援與聯絡方法
- privacy.html：隱私政策
- styles.css：手機與桌面共用樣式
